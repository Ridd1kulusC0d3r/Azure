# Priority Intelligence Requirements

Starter PIRs for an Azure-focused defensive program.

## PIR-01 — Identity compromise
Which identity attack behaviors are most relevant to Entra ID and privileged Azure access?

## PIR-02 — Privilege escalation
Which techniques could allow a compromised identity or workload to gain higher privileges?

## PIR-03 — Persistence
Which Azure, Entra and workload mechanisms can be abused to preserve access?

## PIR-04 — Control-plane abuse
Which Azure Resource Manager operations would materially change security posture?

## PIR-05 — Cloud-native evasion
Which behaviors can reduce visibility, disable controls or bypass expected monitoring?

Each PIR should eventually link to threat scenarios, hunts, detections and coverage status.
