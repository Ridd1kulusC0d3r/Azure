# Collection Plan

## Sources

Prioritize:

1. Microsoft security research and product advisories.
2. CISA and national CERT advisories.
3. MITRE ATT&CK.
4. Vendor incident research with reproducible technical evidence.
5. Internal incident and hunt findings.

## Extract

For each relevant report capture:

- threat / campaign
- affected Azure or Microsoft service
- behavior or TTP
- prerequisites
- observable artifacts
- likely telemetry
- ATT&CK mapping
- confidence
- detection opportunity
- source URL and publication date

## Output

The useful result is not a pile of bookmarks. It is a structured intelligence note that can become a hunt or threat scenario.
