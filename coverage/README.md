# Coverage

Coverage connects threat scenarios to actual observability.

## Coverage states

- **Covered** — tested detection exists.
- **Partially covered** — telemetry or logic captures only part of the behavior.
- **Hunt only** — analyst-led hunting exists but no stable detection.
- **Telemetry gap** — required source is missing.
- **Research gap** — scenario is insufficiently understood.

## Planned matrices

- ATT&CK technique → Azure service
- ATT&CK technique → telemetry
- threat scenario → hunt
- hunt → detection
- detection → validation evidence
